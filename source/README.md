# Handoff: лендинг таргетолога (Meta Ads · TikTok Ads · SMM)

## Overview
Одностраничный лендинг для сбора заявок на таргетированную рекламу, SMM и создание лендингов. Две формы заявки (основная и «лендинг под ключ») отправляют данные в Google Apps Script, который пишет их в Google Таблицу и присылает в Telegram-бот.

## About the Design Files
- `index.html` — готовый самодостаточный файл (фото и скрипты встроены, шрифты с Google Fonts). Можно сразу выложить на хостинг как есть.
- `source/landing.dc.html` — исходник дизайна (HTML-прототип, инлайн-стили). Это **референс**: если нужен полноценный проект (чистый HTML+CSS, Astro, Next.js), воссоздай дизайн в выбранном стеке по спецификации ниже. Без существующей кодовой базы рекомендую статический HTML + CSS + небольшой vanilla JS (или Astro).

## Fidelity
High-fidelity: финальные цвета, типографика, отступы, тексты и анимации. Тексты не переписывать.

## Задачи для Claude Code
1. Выложить сайт на хостинг (Netlify / Vercel / GitHub Pages). Минимум — `index.html` в корень.
2. (Желательно) Пересобрать в чистый HTML+CSS+JS с отдельными файлами, сохранив вид и анимации 1:1. Фото отдавать в WebP/AVIF + `srcset`, чтобы страница весила < 1 МБ (сейчас ~2 МБ из-за встроенных фото).
3. `<title>`, description, Open Graph, favicon уже есть в `<head>` index.html. После выбора домена замени `og-image.png` и `apple-touch-icon.png` в мета-тегах на абсолютные URL (`https://домен/og-image.png`) — иначе Telegram/Instagram не покажут превью. Файлы лежат рядом с index.html, выложить их вместе.
4. Проверить отправку форм на продакшн-домене (см. «Заявки»).
5. Подключить свой домен, если нужно.

## Interactions & анимации
- **Появление секций**: opacity 0→1, translateY 28px→0, 0.7s ease (IntersectionObserver, threshold 0.08).
- **H1 hero**: reveal снизу (clip-path + translateY, 1.3s, cubic-bezier(.2,.7,.2,1)); затем серебряный блик по тексту каждые 6 с. Остальные элементы hero появляются со stagger 120 мс.
- **Фото hero**: Ken Burns scale 1.1→1 за 12 с.
- **Счётчики**: числа (Oswald) крутятся как таймер при входе в экран и останавливаются на исходном значении (1.4 с, easeOutCubic).
- **Карточки** кейсов / форматов / этапов / иконки услуг — stagger-появление (700 мс, шаг 110 мс). Кейсы на десктопе наклоняются за курсором (tilt, perspective 900px).
- **Border Beam** (по мотивам Magic UI): на карточках с тонкой светлой рамкой бежит серебряный луч — `@property --bb-a` + conic-gradient + mask (content-box xor), 5 с, со случайной фазой. **Исключения**: шапка, отзывы, контейнер `#packages` и все строки «Форматов работы», кроме «Полный цикл».
- **Spotlight** (по мотивам Aceternity Card Spotlight): радиальное пятно за курсором (CSS-переменные --mx/--my), только hover-устройства.
- **Shimmer** на кнопках: диагональная полоса (серые края + белый центр) раз в ~3.6 с; на светлых CTA — контрастная, на тёмных pill-кнопках — мягкая.
- **Стрелки** → / ↓ в ссылках сдвигаются при hover.
- **Отзывы, десктоп**: обёртка высотой (высота секции + дистанция ленты), секция `position: sticky` по центру экрана; вертикальный скролл двигает ленту по X с lerp-сглаживанием (0.14). Без библиотек.
- `prefers-reduced-motion: reduce` — все анимации отключены, отзывы — обычная карусель.
- **Формы**: поля name, phone (required), radio messenger (telegram / viber / call), по умолчанию telegram, выбор не должен сбрасываться при ре-рендере. Тап-зона radio ≥ 40px. Во время отправки — «Отправляю…». Успех — карточка «Заявка принята» с текстом по выбранному мессенджеру («свяжусь с вами в Telegram» / «в Viber» / «позвоню»). Ошибка — красный текст #F08A7A.

## Заявки (важно не сломать)
POST на Google Apps Script:
```
https://script.google.com/macros/s/AKfycbyyCM54qBUcazl9Q0l6uJLT4Q8OuEeAyjQ7HGno5JNgicAM1Gg9QbRnQKvOTxJtePLeWQ/exec
```
```js
fetch(URL, { method: "POST", mode: "no-cors",
  headers: { "Content-Type": "text/plain;charset=utf-8" },
  body: JSON.stringify({ name, phone, messenger, source, page: location.href, ts: new Date().toISOString() }) });
```
`source` — фиксированное название формы: «Рассчитать стоимость» (основная форма `#contact`) или «Создание лендинга» (форма `#landing-service`). Ссылка на страницу — отдельным полем `page`. Других форм на сайте нет; все кнопки «Заявка» ведут к форме «Рассчитать стоимость». Скрипт `lead-endpoint.gs` пишет строку в Google Таблицу (колонки: Дата, Имя, Телефон, Связь, Что хочет, Страница) и шлёт сообщение через Telegram-бота. Токен бота хранится в скрипте Google, не в сайте. Телефоны белорусские: +375 29 / 25 / 33 / 44 — не ставить маску, ломающую этот формат.
